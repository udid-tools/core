# Support

## Documentation

Start with the [project documentation](https://udid-tools.github.io/core/) and
the examples in this repository. The API reference, guides, capability matrix,
and security guidance describe the supported beta behavior.

## Questions and troubleshooting

Search existing issues first. If the documentation does not answer your
question, open a regular issue and include:

- Package, Node.js, TypeScript, and package-manager versions.
- A minimal reproduction.
- Expected and actual behavior.
- Sanitized errors or warnings.

Community support is best-effort and has no guaranteed response time.

## Feature and algorithm requests

Use the feature request form for product capabilities and the dedicated
algorithm support request form for new certificate containers, private-key
formats, key algorithms, or digest algorithms. The capability matrix defines
what is currently supported.

## Security

Do not use a public support channel for a suspected vulnerability. Follow
[SECURITY.md](SECURITY.md) and use GitHub Private Vulnerability Reporting.

Never include production private keys, PKCS#12/PFX files, passphrases, tokens,
or unredacted device responses in a support request.
